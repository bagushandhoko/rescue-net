# Pelaporan keamanan Rescue-Net

Kirim laporan secara privat ke email pengelola yang tercantum di [Kebijakan Privasi](pages/kebijakan-privasi.html). Gunakan subjek “Laporan keamanan Rescue-Net”. Sertakan versi atau commit, komponen terdampak, ringkasan dampak, dan bukti dari lingkungan sendiri dengan data simulasi. Jangan sertakan data pribadi, kredensial, atau salinan data produksi. Gunakan kanal privat sebelum membuka isu publik.

Cakupan mencakup aplikasi web, API Frappe, pertukaran data federasi, dan paket instalasi `node/` yang dipelihara dalam repo ini. Pengujian terhadap layanan produksi hanya boleh dilakukan dengan izin tertulis pengelola. Gunakan lingkungan lokal atau lingkungan uji yang diotorisasi.

Pengelola menargetkan konfirmasi penerimaan dalam tujuh hari kalender dan akan memberi kabar setelah penilaian awal, termasuk langkah selanjutnya dan koordinasi pengungkapan.

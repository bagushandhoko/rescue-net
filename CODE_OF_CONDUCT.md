# Kode etik kontribusi

Komunitas Rescue-Net mengikuti [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Hormati perbedaan, sampaikan kritik secara konstruktif, dan jaga privasi orang lain. Pelecehan, serangan pribadi, dan publikasi informasi pribadi tanpa izin dilarang.

Kode etik berlaku di ruang proyek dan ketika seseorang mewakili proyek. Laporkan pelanggaran secara privat kepada pengelola melalui kontak di [Kebijakan Privasi](pages/kebijakan-privasi.html).

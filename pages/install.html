Rescue-Net di HP dan laptop Anda.

Aplikasi Rescue-Net adalah website ini sendiri — dipasang ke layar utama, dibuka tanpa browser, dan halaman lapangan (laporan, posko logistik, medis, shelter, dapur umum, alat kerja, kartu keluarga, scan, kehadiran relawan) tetap bisa dibuka tanpa sinyal. Isian formulir lapangan yang disimpan saat offline tetap tersimpan di HP dan terkirim otomatis saat ada sinyal — tanda “data menunggu sinyal” muncul di pojok kanan bawah.

Unduh APK Android Sudah terpasang di perangkat ini
Cara memasang Android (Chrome): tombol Install di atas, atau menu ⋮ → Install app / Tambahkan ke layar utama. iPhone / iPad (Safari): tombol Bagikan → Add to Home Screen. Windows / Mac / Linux (Chrome, Edge): ikon install di bilah alamat, atau tombol di atas. APK Android: untuk dibagikan lewat WhatsApp / tanpa Play Store. Saat memasang, izinkan “instal dari sumber ini”. Di APK, gunakan login email & password — Google tidak mengizinkan login Google dari dalam aplikasi seperti ini; bila perlu login Google, pakai cara Android (Chrome) di atas.

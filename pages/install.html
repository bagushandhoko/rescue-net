Rescue-Net di HP dan laptop Anda.

Aplikasi Rescue-Net adalah website ini sendiri — dipasang ke layar utama, dibuka tanpa browser, dan halaman lapangan (laporan, posko logistik, registrasi posko, shelter) tetap bisa dibuka tanpa sinyal. Laporan yang dibuat offline tersimpan di perangkat dan terkirim otomatis saat online.

Sudah terpasang di perangkat ini
Cara memasang Android (Chrome): tombol Install di atas, atau menu ⋮ → Install app / Tambahkan ke layar utama. iPhone / iPad (Safari): tombol Bagikan → Add to Home Screen. Windows / Mac / Linux (Chrome, Edge): ikon install di bilah alamat, atau tombol di atas.

Aplikasi lama (Rescue-Net App)

Aplikasi terpisah sebelumnya sudah dipensiunkan. Kalau di HP Anda masih ada laporan yang belum terkirim di aplikasi lama, buka aplikasi lama sekali saat online — antreannya dikirim dulu, lalu Anda diarahkan ke sini.

AI Feature Blueprint

Fitur yang akan diimplementasikan di backend.

  1. Table ai_provider_keys: owner_type user/organization, encrypted key, provider, model.
  2. Table ai_usage_logs: user, organization, question, answer summary, model, usage.
  3. Endpoint POST /ai/settings/keys untuk menyimpan key terenkripsi.
  4. Endpoint POST /ai/ask untuk analisa berbasis data Rescue-Net.
  5. Permission guard agar AI hanya membaca data sesuai hak user.
  6. Answer sources agar jawaban AI bisa ditelusuri ke data.

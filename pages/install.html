Install App

Rescue-Net di HP dan laptop Anda.

Aplikasi Rescue-Net adalah website ini sendiri — dipasang ke layar utama, dibuka tanpa browser, dan halaman lapangan (laporan, posko logistik, medis, shelter, dapur umum, alat kerja, kartu keluarga, scan, kehadiran relawan) tetap bisa dibuka tanpa sinyal. Isian formulir lapangan yang disimpan saat offline tetap tersimpan di HP dan terkirim otomatis saat ada sinyal — tanda “data menunggu sinyal” muncul di pojok kanan bawah.

Sudah terpasang di perangkat ini
Cara memasang Android (Chrome): tombol Install di atas, atau menu ⋮ → Install app / Tambahkan ke layar utama. iPhone / iPad (Safari): tombol Bagikan → Add to Home Screen. Windows / Mac / Linux (Chrome, Edge): ikon install di bilah alamat, atau tombol di atas. Membagikan ke orang lain (WhatsApp dll.): kirim tautan halaman ini — rescue-net.online/rescue-net/pages/install.html — lalu penerima membukanya di Chrome/Safari dan menekan Install. Tidak perlu file APK; aplikasi selalu versi terbaru dan login Google tetap bisa.

Masih ada aplikasi Rescue-Net lama di HP?

Aplikasi lama (yang punya isian “API base” / alamat server) dan APK Android sudah dipensiunkan (November 2026). APK yang sudah terpasang masih bisa dibuka, tetapi tidak bisa login Google. Hapus (uninstall) dulu aplikasi lama, lalu pasang lewat tombol di atas. Aplikasi baru tampilannya sama persis dengan website ini, tanpa pengaturan alamat server.
